Imixs-Diagram – Skill Map

Skills as nested bubbles. Click a bubble to jump into it; click the background, the bubble itself or press Esc to jump out. The breadcrumb jumps to any level. Drag to move, the mouse wheel zooms.
The toolbar below the breadcrumb works on the focused bubble or the clicked skill inside it: + Child, + Sibling, Edit (the host would open its form). A double click shows the path and description of a skill in the property panel. Meta model editor · Org chart
